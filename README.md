# Biblioteca de Préstamos - Modularizado

Sistema de gestión de biblioteca con autenticación, búsqueda, filtrado por categorías y préstamo de libros.

## Estructura

```
biblioteca/
├── index.html
├── css/
│   ├── styles.css
│   ├── auth.css
│   ├── book.css
│   └── modal.css
├── js/
│   └── app.js
└── data/
    └── books.json
```

## Uso

Abre `index.html` en tu navegador.

- Usuario por defecto: `admin`
- Contraseña: `1234`
